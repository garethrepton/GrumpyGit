GRUMPY AI IS EXPERIMENTAL

This is not the standard Grumpy git client. It is a separate, experimental
product, and you should treat its output accordingly.

What that means in practice:

  * The local model's review is a suggestion, not a verdict. It will miss real
    bugs and it will flag things that are fine. Read the diff yourself.
  * Behaviour, settings and the model catalogue may change between releases.
  * It is a much larger download than Grumpy, and reviewing a diff will use
    noticeable CPU and memory while it runs.

What has not changed:

  * Every git operation is the same as in Grumpy. Your repositories are handled
    by git.exe exactly as before.
  * No model weights ship with this installer. You choose one from a short list
    inside the app and press download.
  * The model runs on this machine. Your code is not sent anywhere.

If you want the git client without any of this, install Grumpy instead. The two
sit side by side, and installing this one does not replace it.
